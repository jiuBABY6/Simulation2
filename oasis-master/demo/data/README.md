# 数据接入约定

当前 Demo 不附带真实评论数据。可将评论整理为 UTF-8 JSONL，每行至少包含：

```json
{"comment_id": "c001", "user_id": "u001", "created_at": "2026-07-23T10:00:00+08:00", "text": "希望尽快公布核实结果"}
```

运行入口通过 `--comments` 读取 `text` 字段，并用基线关键词分类器映射到十个群体。关键词分类仅用于打通流程，正式实验应替换为：

1. 按事件/视频隔离数据；
2. 文本去重、广告和机器人过滤；
3. 语义向量聚类；
4. 立场、情绪、可信度与行为倾向联合标注；
5. 每类抽样人工核验；
6. 保存分类模型和聚类版本。

不要将视频评论样本直接解释为全微博用户分布。

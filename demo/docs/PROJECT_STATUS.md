# 当前项目状态

更新日期：2026/09/06。

## 已完成功能

- 独立实验批次、状态重置、输入快照和策略状态隔离。
- 事件角度规划、初始评论池、每轮增量评论及分级兜底。
- Persona读取、个人可见评论、Agent受约束LLM决策和最终表达选择。
- Agent状态历史、个人评论历史和证据时间语义。
- 共享进场前基线、官方动态进场、不回应基线和四种内容策略对照。
- Agent情绪、官方态度、过程效果、数据质量和性能指标。
- 独立历史趋势复现及其只读可视化。
- 评论生成架构优化和性能测量。
- 固定社交网络、Agent影响力权重、邻居评论传播、公共评论补充和个人可见范围内最终表达。
- 五策略共享同一网络快照，进场后在各自状态目录中独立演化。
- 邻居曝光事件、Agent表达谱系、传播层级和逐跳权重衰减。
- 逐轮及场景级传播覆盖、继续传播、最大深度和有效权重指标。

## 当前验证结论

- 10个Agent、10轮、5个场景能够完整运行。
- 优化后单个增量轮次耗时约为11.6～13.9秒。
- 三次同事件稳定性样本合并兜底率约7.1%。
- 高阳商场冲突事件完成首次跨事件验证：5个场景全部成功，单轮增量评论耗时13.725秒，实际兜底率11.0%，HTTP失败为0。
- 当前结果证明Demo核心和性能方案具备初步可用性，不等同于生产级稳定性验证。
- 第二十五次联调已验证第一阶段传播：500次决策无可见范围越界，后9轮约60.2%的最终表达来自邻居传播评论。
- 第二十六次联调已验证第二阶段A：五个场景共记录2117次邻居曝光，最大传播深度为4～6，全部事件的有效权重均按0.7逐层衰减，逐轮和场景传播指标可由原始记录完整重算。

## 暂缓与未完成功能

- 适应性画像和跨事件Agent长期更新暂缓。
- 固定官方回应时机对照实验暂缓。
- 内容策略与声明状态的完整组合实验未实施。
- 数据库、后端API、任务队列和生产级并发调度未建设。
- 动态关注关系和传播参数校准尚未实施。
- 多事件、多规模、多批次统计稳定性仍需继续验证。

## 当前主要风险

- 项目配置仍需完成密钥环境变量化，真实密钥不得进入共享代码。
- 当前运行结果以JSON和JSONL保存，缺少数据库约束和查询接口。
- 五种策略仍串行执行，完整实验耗时受进场轮次和LLM响应速度影响。
- `degraded`表示某些轮次使用较多历史兜底，策略结果需要结合数据质量解释。

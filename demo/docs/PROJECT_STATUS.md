# 当前项目状态

更新日期：2026/10/22。

## 已完成功能

- 独立实验批次、状态重置、输入快照和策略状态隔离。
- 事件角度规划、初始评论池、每轮增量评论及分级兜底。
- Persona读取、个人可见评论、Agent受约束LLM决策；历史模式生成原创表达，新回应方案对照批次可自主选择沉默、原创或转发。
- Agent状态历史、个人评论历史和证据时间语义。
- 共享进场前基线、官方动态进场、一组不回应基线和三个可自定义回应方案对照。
- Agent情绪、官方态度、过程效果、数据质量和性能指标。
- 单一历史趋势复现主线及其只读可视化；第2轮以后不注入真实评论或真实情绪比例。
- 历史 Agent 第一轮情绪由LLM初始化，后续情绪转移和官方态度由受证据约束的个体规则裁决；LLM负责解释、发言意愿和原创表达；不使用本地概率分层、人口配额或结果级群体坍缩熔断。
- 历史主对照使用 Agent 实际发表的评论；内部情绪和生成评论池作为分层诊断口径。
- 历史状态转换要求引用本轮新增证据，Persona依据、情绪依据和官方态度依据可单独审计。
- 历史已核实更新、客观事件和官方声明已按背景/阶段进展/关键事实分级，不再默认全部作为强证据；缺少元数据的旧更新安全降级为阶段性证据。
- 同一证据会按Persona主题偏好、信息取向和上一轮情绪惯性分别计算情绪与官方态度影响，并在`evidence_appraisal`中保存实际引用证据的个体评估。
- 历史路径使用`persona_decision_v3 / personalized_hysteresis_v3 / emotion_transition_v1 / official_attitude_v3`。回应方案路径使用`strategy_directional_utility_v3`：证据按评论目标分流到事件情绪、官方态度和参与通道，权威证据按Persona处理速度在最多三轮内渐进吸收，实际推动一次变化后即停止重复作用；证据再与Persona先验、上一轮惯性和独立传播根共同形成唯一相邻状态。官方态度候选继续由Persona与通告语义独立决定，规则预判和证据记忆不进入LLM提示词。两条路径都保持情绪、官方态度和公开行为相互独立，不读取真实目标比例。
- 回应方案每轮外生LLM增量评论默认由20条降为8条，历史复现仍保留原数量；实际配置随实验结果保存，避免外部评论数量隐式改变。
- 回应方案发言门控已把“是否有新信息”拆为新鲜度、方向性证据相关度和状态效用张力，避免三个回应方案在状态输入不同的情况下仍产生完全相同的参与序列；该门控不按正负情绪设置差别奖励。
- 官方态度已拆分为`claim_position`与`process_evaluation`，避免“接受事实结论”等同于“满意官方处置”；通告`clear`只表示表述清晰，不自动成为强证据。
- 每轮新增官方态度熵、最大群体占比、同步转向率和双维度分布诊断；诊断只记录现象，不终止或改写实验。
- 完整历史实验新增`run_manifest.json`，记录输入、核心代码、模型、温度、随机种子和实际Persona画像指纹，不记录API Key。
- 新官方通告已拆成同一事实组下的可引用证据点，不同信息取向可以关注不同片段，且不会把同一通告重复计为多条独立依据。
- 历史决策已对静默时的多余表达、空派系和无通告时的空态度证据执行可审计规范化；发言决策缺少有效表达或派系仍会失败，避免用默认文本掩盖语义错误。
- 历史公众语境已拆分为公共事实广播和个体讨论曝光；历史事件默认每名Agent关注5人，曝光目标为4条邻居表达和11条公共评论，公共评论按Persona长期偏好做固定种子加权抽样。
- 历史发言资格已与内部状态分离；回应方案对照也实现独立门控，但两者使用各自配置和规则，不互相引用历史时间线逻辑。
- 回应方案对照已进一步拆成纯状态判断、本地行为门控和按需原创表达三阶段；行为门控不再依赖LLM发言意愿，公开表达情绪开放三分类。
- 回应方案原创表达具有独立纠错重试和超长文本可审计句末裁剪；`Ctrl+C`会清理当前仿真子进程，不再只中断父进程等待线程。
- 评论生成架构优化和性能测量。
- 固定社交网络、Agent影响力权重、邻居评论传播、公共评论补充和个人可见范围内最终表达。
- 四个对照场景共享同一网络快照，进场后在各自状态目录中独立演化。
- 邻居曝光事件、Agent表达谱系、传播层级和逐跳权重衰减。
- 回应方案邻居池扩展到最近3轮，按轮龄优先、根传播链去重和时间衰减抽样；邻居不足后才由公共评论补足，并保存有效曝光率诊断。
- 逐轮及场景级传播覆盖、继续传播、最大深度和有效权重指标。
- 根目录依赖清单和LLM密钥环境变量读取机制。
- 可视化已重构为历史复现、回应方案对照和共享网络三层；回应方案对照新增Agent内部情绪、Agent实际表达情绪和官方态度三张逐轮图，并兼容旧批次原始指标；两类实验继续共用逐轮网络和评论传播链。
- 围绕新建实验和历史查询的数据库、后端、JavaScript前端任务、公共接口与本地验收文档。

- 2026/10/22已把北国先天下当前可运行事件统一为`event_beiguo_xiantianxia_crash_20260920_002`（新数据三阶段版）。旧`001`事件源不再作为运行入口；旧真实趋势JSON和旧实验批次继续只读保留，用于历史结果兼容。
- 2026/10/22交接前离线回归：`demo/tests` 172项全部通过，`persona_pipeline/tests` 4项全部通过，`visualization/tests` 22项通过、4项因本地不存在相应可选旧实验目录而跳过。
- 交接目录最终保留8个状态为`completed`的实验批次：1个保定驾校历史复现、2个北国先天下历史复现、1个胡鑫宇历史复现，以及4个高阳回应方案里程碑批次。失败、部分失败、无总结果和未引用的中间批次已经清理，不再作为交接数据。
- 2026/10/19批次`event_gaoyang_assault_001_20261019_112035_030498`已完成4场景运行，验证`strategy_directional_utility_v1`能区分方案效果且未出现100%同步转向。其后新增的`strategy_directional_utility_v3`目标通道路由、Persona渐进吸收、多维通告聚合和8条外生增量配置已通过离线回归，尚未执行新的完整DeepSeek批次。
- 优化后单个增量轮次耗时约为11.6～13.9秒。
- 三次同事件稳定性样本合并兜底率约7.1%。
- 高阳商场冲突事件完成首次跨事件验证：5个场景全部成功，单轮增量评论耗时13.725秒，实际兜底率11.0%，HTTP失败为0。
- 当前结果证明Demo核心和性能方案具备初步可用性，不等同于生产级稳定性验证。
- 第二十五次联调已验证第一阶段传播：500次决策无可见范围越界，后9轮约60.2%的最终表达来自邻居传播评论。
- 第二十六次联调已验证第二阶段A：五个场景共记录2117次邻居曝光，最大传播深度为4～6，全部事件的有效权重均按0.7逐层衰减，逐轮和场景传播指标可由原始记录完整重算。
- 第二十六次联调共生成900条增量评论，其中历史兜底165条，按统一口径计算实际兜底率为18.3%；这高于早期性能稳定性样本，说明传播功能有效，但评论生成质量仍会随事件和批次波动。

## 当前主要风险

- 共享版本只允许通过`DEEPSEEK_API_KEY`环境变量读取密钥；每次提交前仍需检查配置、日志和实验数据，防止本机密钥被提交。
- 当前工作区包含尚未提交的大量源码、文档、实验结果和事件数据变更；接手人必须先执行交接文档中的只读哨兵，不得用`reset`、`clean`或`stash`覆盖现场。
- 最新机制`strategy_directional_utility_v3`只有离线回归证据。当前保留的最近完整四场景批次`event_gaoyang_assault_001_20261020_141414_286129`早于最终机制，不能作为最终效果验收。
- 当前运行结果以JSON和JSONL保存，缺少数据库约束和查询接口。
- 三个回应方案和一组不回应基线仍串行执行，完整实验耗时受进场轮次和LLM响应速度影响。
- `degraded`表示某些轮次使用较多历史兜底，策略结果需要结合数据质量解释。

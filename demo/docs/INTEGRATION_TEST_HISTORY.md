### 第三次联调问题一：全局趋势 JSON 截断

`no_response` 第 9 轮趋势分析累计输入 60 条初始评论和 160 条增量评论，共 220 条。提示词约 46,567 个字符，但模型输出没有限制证据编号数量，最终返回的 JSON 字符串在中途截断；相同提示词和温度为 0 的请求重试后仍然失败。

处理方式：

- 趋势分析改为比较初始评论和当前轮增量评论，不再输入全部累计增量评论。
- `reason` 限制为 100 字，`evidence_comment_ids` 最多保留 5 个。
- 趋势输出上限调整为 2,000 tokens。
- 模型服务记录 `finish_reason` 和输出字符数，明确识别长度截断。

### 第三次联调问题二：兜底上限不足

`handling_progress` 第 6 轮经过生成和补齐后得到 17 条有效评论，还缺 3 条，超过当时每轮 2 条的兜底上限，因此按规则停止。

处理方式：将每轮历史评论兜底上限调整为 3 条。候选仍排除已被 Agent 选择、已作为兜底来源、字段不完整和与本轮新评论重复的评论，并继续保存 `fallback_count`、`source_type` 和 `source_comment_id`。

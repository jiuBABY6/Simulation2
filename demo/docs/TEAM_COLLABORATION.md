# 团队协作规范

## 当前负责人边界

- 仿真核心负责人：维护规则、数据契约和回归验收。
- 数据库负责人：负责持久化和查询，不修改Agent决策逻辑。
- 后端负责人：负责任务和API，不复制仿真算法。
- 前端负责人：只通过接口或只读结果展示数据。
- 扩展算法负责人：在独立模块中实现，经接口评审后接入。

## 修改规则

1. 修改字段前先更新`DATA_CONTRACT.md`。
2. 修改函数职责前先更新`SIMULATION_INTERFACE_SPEC.md`。
3. 大模型请求只能通过`infrastructure/llm_service.py`。
4. 不覆盖`demo/experiments`中的已有批次。
5. 不在数据库或后端中复制Agent决策、进场和指标公式。
6. 新功能默认保持现有JSON结果向后兼容。
7. 不提交API密钥、个人路径和临时状态文件。

## 提交前检查

- 运行`python -m compileall -q demo`；
- 验证修改模块的最小输入；
- 检查异常信息是否明确；
- 检查JSON和JSONL能否重新读取；
- 说明修改文件、行为变化和验证结果；
- 涉及完整联调时更新`INTEGRATION_TEST_HISTORY.md`。

## 完成定义

任务只有在代码、数据结构、错误处理、最小验证和文档全部完成后才算结束。只完成页面、表结构或函数主体，但没有可复核输入输出，不视为交付完成。
